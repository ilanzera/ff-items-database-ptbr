# Free Fire Items Database | PT-BR

Um banco de dados completo, com código aberto para uso, onde poderão buscar itens do jogo Free Fire. Você pode encontrar ID's, nomes e imagens. Totalmente criado para a comunidade de Free Fire!

## Demo

[Live](https://ilanzera.github.io/ff-items-database-ptbr/)

## Funções

- 🔍 **Buscar:** Encontre itens através de seus nomes, ID's ou pelo nome de seus ícones.
- 🎨 **Filtrar por Item:** Resultados mais precisos, filtrando por tipo de item e categoria da coleção.
- 📦 **Imagens:** Imagens retiradas diretamente do jogo, onde não contém imagens, não contém ícones dos ids no jogo.
- 🖥️ **UI Moderna:** Interface de usuário prática e simples para melhorar a busca.
- 🛠️ **Alterações ao vivo:** Veja os mais recentes commits do repositório para acompanhar as atualizações do projeto.
- ♿ **Acessibilidade:** Navegação rápida por teclado e site Mobile/PC totalmente otimizados e funcionais.

## Fonte dos Dados

- `/assets/itemData_traduzido.json` – Banco de Dados principal em PT-BR
- `/assets/icons` – Imagens mapeadas para os itens
